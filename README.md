# 每日有数 · 手机记账应用

一个无需后端、无需数据库、无需安装依赖的手机网页记账应用。所有代码均在本仓库中，可以自行修改与部署。

## 功能

- 首次设置开始日期及初始余额。
- 新增记录自动使用手机当地当天日期，无需手动输入日期。
- 每日记录多笔分类收入与支出，备注可选。
- 当前余额与每日余额自动累计；无收支日期继承上一日余额。
- 修改、删除及调整历史日期后，余额自动重新计算。
- 按月、年、自选时间范围统计；分类汇总、占比与明细查看。
- 自定义收入、支出类别。
- 导出真正的 .xlsx 文件，包含收支明细、每日余额、分类汇总、账本设置。
- JSON 完整备份与恢复。

## 上传到 GitHub 并发布

1. 解压下载的 ZIP，在自己的 GitHub 账号下新建一个仓库，例如 `daily-balance`。
2. 上传此文件夹内的所有文件到仓库根目录。确保 `index.html` 直接位于仓库根目录，不要只上传 ZIP，也不要多套一层目录。
3. 打开仓库的 **Settings → Pages**，选择从分支部署（Deploy from a branch）。
4. 选择保存代码的分支（一般是 `main`），目录选择根目录 `/ (root)`，保存。
5. 等待 GitHub Pages 部署完成，打开 Pages 页面提供的网址，即可在手机上使用。

不需要配置密钥、安装 npm、运行构建命令或购买服务器。若账号或仓库政策不支持 Pages，请按 GitHub 提示调整配置。公开仓库的源码可被他人看到，但你的账本记录不会上传到仓库。

## 手机上使用

首次打开：进入“设置与备份”，设置初始余额；然后点击“记一笔”。

用 Safari 或 Chrome 等常用浏览器打开自己的 Pages 网址，可通过浏览器菜单添加到主屏幕。请一直使用同一个浏览器和同一个网址。主屏幕模式与普通浏览器的数据共享行为取决于手机系统。

## 数据与备份（重要）

- 账本数据仅保存在当前浏览器的 localStorage，不会自动上传到 GitHub，也不会跨设备同步。
- 不要在无痕模式中长期记账。清除浏览器数据、换浏览器、换手机或换域名可能导致原账本无法访问。
- 请定期导出“完整备份”（JSON）。换手机后打开应用，导入 JSON 即可恢复。
- Excel 用于电脑查看，不用于恢复；恢复必须使用 JSON 备份。
- 从其他网址迁移到自己的 GitHub Pages：先在原网址导出 JSON，再到新网址恢复。
- 恢复备份会替换现有账本，请先备份现有数据。
- 本版本需要联网打开页面，不包含离线缓存服务。

## 本地预览

在文件夹中运行 `python -m http.server 8000`，再用浏览器打开 `http://localhost:8000`。正式使用建议通过 HTTPS 的 GitHub Pages。
